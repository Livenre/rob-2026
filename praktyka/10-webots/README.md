## Д1. Коло без Arduino

| Компонент | Значення |
|---|---|
| 9V Battery | — |
| Resistor | **470 Ом** |
| LED | червоний |
| Multimeter × 2 | один — Voltage, один — Current |

```
+9 В → резистор 470 Ом → анод LED (довша ніжка) → катод → амперметр → −9 В
вольтметр — паралельно світлодіоду (щупи на його ніжки)
```

Показати по черзі:

1. Вольтметр на світлодіоді → ≈ 2 В. Перекинути на резистор → ≈ 7 В. Сума = 9 В.
2. Амперметр — **в розрив**, послідовно → ≈ 15 мА. Перевірка: (9 − 2) / 470 ≈ 0,015 А.
3. ⭐ Замінити резистор дротом → Tinkercad позначить світлодіод як пошкоджений.

## Д2. Цифровий вихід

```
пін 8 → 220 Ом → анод LED → катод → GND
мультиметр (Voltage): «+» на пін 8, «−» на GND
```

Мультиметр перескакує 0 ↔ 5 В. З `PAUZA = 20` мультиметр уже не встигає —
питання до залу «що він тепер показує і чому».

## Д3. Кнопка і загублені натискання

```
Pushbutton: одна пара ніжок на пін 2, протилежна — на GND
пін 8 → 220 Ом → LED → GND
```

1. `ZATRYMKA = 0` → кожне натискання з'являється в Serial Monitor.
2. `ZATRYMKA = 1000` → коротко клацати 10 разів → у моніторі менше 10.
   «Програма спала, коли ви натискали».

## Д4. Потенціометр і АЦП

```
Potentiometer: лівий вивід → 5V, правий → GND, середній (повзунок) → A0
мультиметр (Voltage): «+» на A0, «−» на GND
```

Крутити повзунок під час симуляції: 0 / середина / до упору. Serial Monitor
і мультиметр мають давати ту саму напругу.

## Д5. ШІМ на осцилографі

```
пін 9 → 220 Ом → LED → GND
Oscilloscope: «+» на пін 9, «−» на GND; у властивостях Time per division ≈ 1 ms
мультиметр (Voltage) — теж між піном 9 і GND
```

Показати `ZNACHENNYA` = 64, 127, 191 (між ними — зупинити симуляцію, змінити
число, запустити). Ширина прямокутників росте, висота — завжди 5 В.

## Д6. Нічник

```
5V → Photoresistor → A0 → Resistor 10 кОм → GND
пін 9 → 220 Ом → LED → GND
```

Під час симуляції клацнути фоторезистор — з'явиться повзунок освітленості.

1. `PROPORTSIYNO = false` → різко вмик/вимик біля `PORIH`.
2. Зняти з Serial Monitor `n` при найтемнішому й найсвітлішому, вписати
   в `NMIN` / `NMAX`, `PROPORTSIYNO = true` → плавно.
   «Ось це і є калібрування — на тижні 11 ви робитимете його в Webots».
